# AI Финансовый помощник

Telegram-бот для личного учёта доходов и расходов в UZS и USD. Первая версия рассчитана на нескольких пользователей: данные и настройки каждого пользователя будут храниться отдельно.

## Текущий этап

Бот создаёт SQLite-базу в `data/finance_bot.sqlite3`. Выбор русского или узбекского языка хранится отдельно для каждого Telegram-пользователя и сохраняется после перезапуска. Через главное меню уже можно вручную добавить доход или расход: указать сумму, валюту, категорию и описание, а затем подтвердить сохранение. Записи привязаны к Telegram ID пользователя. Курс USD/UZS хранится на уровне пользователя; его настройка в меню пока ещё заглушка.

Согласованный объём проекта описан в [`Project_plan.md`](Project_plan.md), ход работ — в [`tasks.md`](tasks.md).

## Требования

- Python 3.11 или новее
- Telegram Bot Token от BotFather

## Локальный запуск

1. Создайте виртуальное окружение: `python -m venv .venv`
2. Активируйте его в PowerShell: `.venv\Scripts\Activate.ps1`
3. Установите зависимости: `pip install -r requirements.txt`
4. Скопируйте `.env.example` в `.env` и укажите токен бота.
5. Запустите: `python bot.py`

Не добавляйте `.env` и реальные токены в GitHub.

## Планируемые команды первой версии

- `/start` — выбор языка и главное меню
- `/help` — подсказка по основным действиям
- `/cancel` — отменить ввод операции
- `/balance` — баланс в сумах, долларах и общий эквивалент в сумах
- `/report` — выбор периода и Excel-отчёт
- `/rate` — настройка курса USD/UZS

Операции подтверждаются перед сохранением. Редактирование и удаление уже сохранённых операций добавим отдельным этапом.
