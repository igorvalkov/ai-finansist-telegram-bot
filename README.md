# AI Финансовый помощник

Telegram-бот для личного учёта доходов и расходов в UZS и USD. Первая версия рассчитана на нескольких пользователей: данные и настройки каждого пользователя будут храниться отдельно.

## Текущий этап

Бот создаёт SQLite-базу в `data/finance_bot.sqlite3`. Выбор русского или узбекского языка хранится отдельно для каждого Telegram-пользователя и сохраняется после перезапуска. Через главное меню уже можно вручную добавить доход или расход: указать сумму, валюту, категорию и описание, а затем подтвердить сохранение. Записи привязаны к Telegram ID пользователя. В меню доступны баланс отдельно в UZS и USD и настройка личного курса USD/UZS; общий эквивалент показывается после задания курса. В разделе отчётов можно скачать Excel за текущую неделю или месяц: сводка и операции, диаграммы по категориям и динамика доходов/расходов. Валюты отображаются отдельно.

Согласованный объём проекта описан в [`Project_plan.md`](Project_plan.md), ход работ — в [`tasks.md`](tasks.md).

## Требования

- Python 3.11 или новее
- Telegram Bot Token от BotFather

## Локальный запуск

1. Создайте виртуальное окружение: `python -m venv .venv`
2. Активируйте его в PowerShell: `.venv\Scripts\Activate.ps1`
3. Установите зависимости: `pip install -r requirements.txt`
4. Скопируйте `.env.example` в `.env` и укажите токен бота.
5. Запустите: `python bot.py`

Не добавляйте `.env` и реальные токены в GitHub.

## Действия бота

- `/start` — выбор языка и главное меню
- `/help` — подсказка по основным действиям
- `/cancel` — отменить ввод операции
- Главное меню: баланс, личный курс USD/UZS и список операций.
- «Отчёт»: выбрать текущую неделю или месяц и скачать Excel.

Операции подтверждаются перед сохранением. Для разбора обычного текста сообщение передаётся Groq API; бот показывает распознанные поля и ничего не сохраняет до подтверждения пользователя. Сохранённые операции можно просматривать, изменять и удалять через кнопки; изменения и удаление требуют подтверждения.


Для текстового разбора укажите GROQ_API_KEY и GROQ_TEXT_MODEL в .env; пример есть в .env.example.
