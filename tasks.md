Добавлена проектная конфигурация Context7 MCP в `.codex/config.toml`: HTTPS endpoint, allowlist двух справочных инструментов, без ключей в репозитории. В `AGENTS.md` добавлено ограничение не отправлять Context7 секреты, финансовые данные или непубличный код. Проверка через `codex mcp list` не завершилась: CLI в текущей shell-среде не разрешил `CODEX_HOME`; загрузку сервера в Codex runtime нужно подтвердить после доверия папке/перезагрузки. Добавлены repo-local навыки `.agents/skills/finance-bot-tester/` и `.agents/skills/security-review/`; `AGENTS.md` требует применять их к каждому релевантному изменению кода. Создан публичный `igorvalkov/ai-finansist-telegram-bot`, в него загружены файлы проекта; прежний `obucheniye` оставлен без изменений. Проверка навыков валидатором и Python-тесты ожидают рабочей среды Python; локальная Git-история ещё не синхронизирована с новым репозиторием.


Этап баланса и ручного курса: в `database.py` добавлены персональный курс, подсчёт чистого баланса отдельно по валютам через `Decimal` и валидация положительных конечных сумм при сохранении. В `bot.py` добавлены двуязычные кнопочные сценарии просмотра баланса и ввода/отмены курса. Добавлены unit-тесты на нулевой баланс, точность, изоляцию пользователей и ошибочные суммы/курсы. `git diff --check` прошёл; Python unit-тесты не запустились из-за недоступного Windows Store alias, Telegram-интеграция не проверена. Ручной security-review не выявил межпользовательского доступа: все операции используют Telegram ID отправителя, SQL параметризован, финансовые вычисления используют Decimal; динамические проверки недоступны. README обновлён, имя репозитория в плане исправлено.

Этап управления сохранёнными операциями: добавлены постраничный список, просмотр операции, редактирование типа, суммы, валюты, категории, описания и даты, а также подтверждение перед редактированием/удалением. Обработчики и методы БД используют Telegram ID владельца; SQL параметризован, callback-данные проверяются по FSM и ID операции; перед изменением/удалением сравнивается исходная запись, чтобы отвергать устаревшее подтверждение. Добавлены тесты доступа, CRUD, валидации и пагинации. Python-тесты не запустились (Windows Store alias недоступен), Telegram-интеграция не проверена. README обновлён.


Этап разбора текстовых сообщений: добавлен `ai_parser.py` с асинхронным запросом к Groq Chat Completions, строгой JSON Schema на модели `openai/gpt-oss-20b`, ограничением длины/ответа и локальной проверкой типа, суммы, валюты, категории и даты. `GROQ_TEXT_MODEL` читается из `.env`; `.env.example` обновлён. В `bot.py` добавлен RU/UZ обработчик обычного текста в неактивном FSM-состоянии: неполные/нефинансовые ответы приводят к уточнению/отказу, валидный разбор показывается для подтверждения, сохранение остаётся за кнопкой. README сообщает о передаче текста Groq. Unit-тесты на синтетических RU/UZ случаях и заглушках добавлены в `tests/test_ai_parser.py`; вызов `python -m unittest discover -s tests -v` не запустился из-за недоступного Windows Store `python.exe`. Живых API-вызовов не делали. Ручной security-review: ввод ограничен 2000 символами, ответ 32 КБ, HTTP timeout 20 секунд, секреты/сообщения не логируются, вывод модели валидируется, не записывается без подтверждения; реальный провайдерный сценарий остаётся непроверенным.


Этап отчётов: добавлена выборка операций текущей недели/месяца по календарным датам Asia/Tashkent, ограниченная Telegram ID пользователя и 10 000 записей. Workbook содержит сводку отдельно в UZS/USD, детали, круговые и столбчатые диаграммы расходов и дневной график доходов/расходов, с отдельными рядами по каждой валюте. Денежные вычисления выполняются через Decimal; пользовательские текстовые поля в Excel записываются как литералы для защиты от формул, экспорт ограничивает объём данных. Отчёт отправляется только в личном чате. Добавлены `report_excel.py`, `tests/test_reports.py`, зависимость openpyxl и двуязычные кнопки. `python -m unittest discover -s tests -v` не запустился: Windows Store `python.exe` недоступен; Telegram-интеграция не проверена. Передача аудио Groq не реализуется по решению пользователя.
